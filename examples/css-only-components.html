What is UIKit Modern?

UIKit Modern is a collection of CSS utilities and components that leverage the latest web standards. It's built with CSS custom properties, Grid, Flexbox, and other modern features.

Why use CSS-only components?

CSS-only components are more performant, have smaller bundle sizes, and work without JavaScript. They're perfect for progressive enhancement and accessibility.

What browsers are supported?

Modern browsers with support for CSS Custom Properties, Grid, Flexbox gap, and Container Queries. Chrome 105+, Firefox 110+, Safari 16+, Edge 105+.

Installation

npm install uikit
npm run build-modern

Then include the CSS file in your HTML:

<link rel="stylesheet" href="dist/css/uikit-modern.min.css">

Usage

Add the uk-modern class to your body tag:

<body class="uk-modern">
  <h1 class="uk-h1-modern">Hello World</h1>
</body>
